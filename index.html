Política de Privacidade do Eme Code

A sua privacidade é importante para nós. Esta Política de Privacidade explica como o aplicativo Eme Code trata informações, dados e conteúdos durante sua utilização.

Ao utilizar o Eme Code, você declara estar ciente das práticas descritas neste documento.

1. Sobre o aplicativo

O Eme Code é um aplicativo de desenvolvimento que permite criar, editar e visualizar projetos utilizando tecnologias como HTML, CSS, JavaScript e XML, além de oferecer ferramentas adicionais, recursos de inteligência artificial e instalação de aplicativos por meio de widgets.

2. Login e autenticação

O Eme Code oferece a possibilidade de autenticação utilizando uma conta Google por meio do Firebase Authentication.

Durante esse processo, informações necessárias à autenticação, como identificador da conta, endereço de e-mail e informações básicas do perfil disponibilizadas pelo Google, podem ser processadas para permitir o funcionamento do login.

Essas informações são tratadas pelos serviços de autenticação do Google Firebase, conforme suas respectivas políticas.

Mais informações: Privacidade e segurança do Firebase .

3. Projetos e arquivos armazenados localmente

Os projetos criados ou editados no Eme Code são armazenados localmente no dispositivo do usuário.

Isso inclui arquivos e conteúdos relacionados a HTML, CSS, JavaScript e XML.

O usuário mantém o controle sobre seus projetos e pode editar, salvar ou excluir seus arquivos.

Atualmente, o Eme Code não realiza sincronização automática dos projetos com o Firebase Firestore ou outro serviço de armazenamento em nuvem.

4. Aplicativos instalados por widgets

O Eme Code disponibiliza um recurso que permite utilizar projetos como aplicativos por meio de widgets.

Para esse funcionamento, os arquivos necessários são copiados e armazenados em uma pasta separada daquela utilizada pelo editor principal.

Os aplicativos instalados utilizam essas cópias locais dos arquivos para funcionar.

Os dados gerados durante a utilização desses aplicativos, incluindo informações armazenadas em arquivos JSON, permanecem no próprio dispositivo.

Atualmente, esses dados não são sincronizados com servidores em nuvem pelo Eme Code.

5. Recursos de inteligência artificial

O Eme Code disponibiliza recursos de inteligência artificial que podem ser utilizados mediante configuração de uma chave de API própria pelo usuário.

Quando o usuário utiliza esses recursos, os textos, comandos e códigos enviados para processamento podem ser transmitidos ao provedor de inteligência artificial selecionado.

Entre os provedores que podem estar disponíveis estão:

  • Google Gemini;
  • Groq;
  • OpenRouter;
  • Outros provedores disponibilizados no aplicativo.

O processamento dessas informações ocorre de acordo com as condições, políticas de privacidade e práticas de tratamento de dados de cada provedor.

O usuário é responsável pela utilização de sua própria chave de API e deve evitar enviar informações confidenciais, senhas ou dados pessoais desnecessários nas solicitações.

O Eme Code não garante as práticas de privacidade, armazenamento ou retenção de dados adotadas pelos provedores externos.

6. Publicidade e Google AdMob

O Eme Code pode exibir anúncios por meio do Google AdMob.

O serviço de publicidade pode coletar e processar determinadas informações do dispositivo e dados relacionados à publicidade, conforme suas configurações e políticas aplicáveis.

Essas informações podem incluir identificadores de publicidade, informações técnicas do dispositivo, dados de interação com anúncios e informações necessárias à prevenção de fraudes.

O tratamento dessas informações é realizado de acordo com as políticas do Google.

Mais informações: Política de Privacidade do Google .

7. Compartilhamento de informações

O Eme Code não comercializa os projetos, códigos ou arquivos locais dos usuários.

Entretanto, determinadas informações podem ser processadas por serviços externos necessários ao funcionamento dos recursos utilizados.

Esses serviços incluem:

  • Google Firebase, para autenticação;
  • Google AdMob, para publicidade;
  • Provedores de inteligência artificial escolhidos pelo usuário, para processamento de solicitações.

Cada serviço possui suas próprias condições de uso e políticas de privacidade.

8. Armazenamento e segurança

O Eme Code utiliza armazenamento local para manter projetos, arquivos e dados necessários ao funcionamento de seus recursos.

As informações armazenadas localmente estão sujeitas às condições de segurança do próprio dispositivo.

Recomendamos que o usuário mantenha seu dispositivo protegido e realize cópias de segurança dos arquivos importantes.

Embora sejam adotadas medidas para proteger as informações, nenhum sistema pode garantir segurança absoluta contra todos os riscos.

9. Retenção e exclusão de dados

Os projetos e arquivos armazenados localmente podem ser excluídos pelo próprio usuário, por meio das funcionalidades disponíveis ou dos recursos de gerenciamento de arquivos do dispositivo.

O usuário também pode excluir sua conta do Eme Code diretamente pelo aplicativo, sem precisar enviar uma solicitação por e-mail.

Para realizar a exclusão, é necessário estar conectado à conta no aplicativo. Em seguida, basta acessar as configurações, onde o botão Excluir minha conta ficará disponível. Ao tocar nele, o aplicativo solicitará a confirmação do usuário. Após a confirmação e a autenticação necessária, a exclusão será realizada automaticamente pelo aplicativo.

Atualmente, a exclusão remove a conta e os dados de autenticação associados a ela no Firebase Authentication. O Eme Code não mantém projetos ou outros dados pessoais associados à conta em um banco de dados na nuvem.

A exclusão da conta não apaga automaticamente os projetos, arquivos e demais conteúdos armazenados localmente no dispositivo do usuário.

Para consultar o procedimento completo de exclusão, acesse: Página de Exclusão de Conta do Eme Code .

Informações eventualmente mantidas por serviços externos seguem as regras de retenção e exclusão dos respectivos provedores.

10. Permissões do dispositivo

O aplicativo pode solicitar permissões necessárias ao funcionamento de seus recursos, incluindo acesso a arquivos e armazenamento, conexão com a internet e outras permissões relacionadas às funcionalidades utilizadas.

As permissões são utilizadas para permitir o funcionamento dos recursos correspondentes.

11. Privacidade de crianças

O Eme Code não é desenvolvido especificamente para crianças.

Não coletamos intencionalmente dados pessoais de crianças de maneira incompatível com a legislação aplicável.

12. Serviços de terceiros

O aplicativo utiliza serviços externos que possuem suas próprias políticas de privacidade.

Consulte:

  • Política de Privacidade do Google
  • Privacidade do Firebase
  • Privacidade do OpenRouter
  • Privacidade da Groq

13. Alterações nesta política

Esta Política de Privacidade poderá ser atualizada sempre que necessário, especialmente quando novas funcionalidades forem adicionadas ao aplicativo ou quando houver mudanças nos serviços utilizados.

A versão atualizada será disponibilizada nesta mesma página, acompanhada da data da última atualização.
